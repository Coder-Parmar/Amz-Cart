# Amz-Cart-E-commerse_Website-
AmzCart – A modern, responsive anime-inspired fashion e-commerce storefront built using HTML5 and CSS3. Features stylish hero banners, product collections, interactive hover effects, and responsive CSS Grid layouts for anime-themed T-shirts, hoodies, track pants, and sneakers.



# 🛍️ AmzCart --- Anime Fashion Store

**Wear Your Anime Vibe.**

A responsive anime-inspired clothing storefront built with **HTML5 and
CSS3**.
:::📌 About the Project
AmzCart is a front-end e-commerce website concept for anime fans. It
showcases anime-inspired T-shirts, hoodies, track pants, sneakers and
accessories in a dark, purple-accented storefront.

The project focuses on a consistent visual identity, product
presentation, CSS Grid layouts, positioning, hover effects and
responsive design.
✨ Features
- Dark black-and-purple storefront theme
- Brand navigation and product search field
- Two promotional hero banners
- Product sections:
  - Trending Now
  - Hoodies
  - T-Shirts
  - Track Pants
  - Sneakers
- Product cards with images, names, prices and original prices
- CSS Grid product layout
- Hover effects on product cards, images and buttons
- Responsive layout for desktop, tablet and mobile screens
- Hero banner links to the product section
🧰 Built With
- HTML5 --- page structure
- CSS3 --- styling, Flexbox, CSS Grid, positioning, transitions
  and media queries

🚀 Run Locally
1. Clone this repository:
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
2. Open the project folder:
   cd YOUR-REPOSITORY
3. Run the website:
   Open index.html in your browser.
   For a smoother development experience, open the folder in Visual
   Studio Code and use the Live Server extension.

The banner images are designed at 1450 × 500 pixels. The clickable
areas are positioned over the button artwork using CSS. If you replace
or resize a banner, adjust the corresponding clickable-area positions in
style.css.
🎨 Customisation
- Replace the logo in logo&Hero-Banner/.
- Replace the hero images while keeping the filenames or updating the
  HTML paths.
- Add or edit products in index.html.
- Change colours, spacing, typography and responsive breakpoints in
  style.css.
- Update navigation links to match your section IDs.
⚠️ Current Scope
This is a front-end-only project. The search field and Add to Cart
buttons are visual elements and do not yet provide working search, cart,
checkout or payment functionality. The hero banner links navigate to
sections on the page.
